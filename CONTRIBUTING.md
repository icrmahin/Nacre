# Contributing

Changes should preserve Nacre's visual hierarchy and keep the color, file-icon, and product-icon contributions independently selectable.

Before opening a pull request:

1. Keep the package ID `icrmahin.nacre` stable unless a deliberate identity change is approved.
2. Do not remove or overwrite the existing license notices.
3. When changing icon assets, update all relative mappings and verify every referenced file exists.
4. Run `npm run validate`.
5. Include a concise explanation and before/after screenshots for visual changes.
6. Do not commit personal tokens, credentials, machine-specific settings, or unrelated project files.
